# DUSTLINE

Baja desert racing in the browser: Trophy Trucks and Pre-Runners on a desert course or a dune sea, day or night.
Play it at https://jjbirnbaum-beck.github.io/dustline/ (desktop browser, keyboard or gamepad).

Controls: W/S throttle and brake, A/D steer, Space handbrake, C camera, X cinematic side cam, R reset, Esc pause.
